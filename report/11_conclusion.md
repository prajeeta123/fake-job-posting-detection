# 10. Conclusion

This project developed an end-to-end fake-job-posting screening workflow and local Streamlit application. The system combines TF-IDF text, job metadata, and deterministic scam-indicator/count features in a complete saved pipeline. A balanced Linear SVM was selected using training-only validation PR-AUC and sigmoid-calibrated with training data. A separate training-only validation procedure selected a fraud-F1 threshold of 0.40 (validation F1 0.8441) and identified 0.15 as a higher-recall alternative (validation recall 0.9270).

The hybrid model comparison reported a fraud F1 of 0.8161 for the selected Linear SVM and 0.8488 for XGBoost on the held-out test comparison. Against the project's text-only LinearSVC baseline (F1 0.8360), the hybrid Linear SVM had higher fraud recall and AUC values but lower precision and F1; hybrid XGBoost had a higher F1, though that comparison also changes the classifier family. Model selection followed validation PR-AUC and did not use test results. A separate verification of the saved calibrated SVM reported fraud precision 0.8662, recall 0.7907, and F1 0.8267 at its default prediction rule; those metrics were not evaluated at the app's selected threshold of 0.40.

The app demonstrates local inference and presents its output as a risk estimate with warning indicators and safety guidance. Error analysis and SHAP explanations emphasize that individual features can contribute to predictions without proving fraud. Accordingly, the system is a screening aid, not an authority on a posting's authenticity. Stronger conclusions require external validation, continued monitoring, and human verification.
