# Abstract

Online recruitment fraud can expose job seekers to financial loss, identity theft, and misuse of personal information. This project develops a local fake-job-posting screening system using the 17,880-row job advertisement dataset in `data/raw/DataSet.csv`. The hybrid pipeline combines TF-IDF features from five posting-text fields with 11 categorical metadata fields and 16 numeric counts and rule-based indicators. After removing 235 exact duplicate rows, 17,645 postings remain, including 858 fraudulent examples (4.86%).

Four hybrid classifier families were compared on the same stratified split. A balanced Linear Support Vector Machine (SVM) was selected by training-only validation PR-AUC (0.9273), with fraud F1 as a tie-breaker, and was sigmoid-calibrated for probability output. In the held-out comparison, this hybrid SVM achieved fraud precision 0.8068, recall 0.8256, F1 0.8161, ROC-AUC 0.9856, and PR-AUC 0.8958. The text-only LinearSVC baseline achieved F1 0.8360 and recall 0.7558; thus, the hybrid SVM improved recall and both AUC measures in this experiment, while lowering precision and F1. Hybrid XGBoost obtained test fraud F1 0.8488, but the test results were not used to select the deployed model. Separately, training-only threshold analysis selected 0.40 for validation fraud F1 (0.8441) and identified 0.15 as an alternative meeting the validation recall target (0.9270).

The saved pipeline and threshold power a local Streamlit interface. Error analysis and SHAP explanations show that both false alarms and missed fraud remain, and that feature contributions describe model behavior rather than prove fraud. Results are specific to this dataset and split; the application is a screening aid, not an authenticity verifier.
